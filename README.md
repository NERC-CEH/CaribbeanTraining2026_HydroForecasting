Welcome to the GitHub repository for Phase II of the WMO Caribbean Region Instructor-Led Course on Seasonal Hydrological Forecasting.

This repository serves as the hub for the notebooks used during the Phase II of the online INstructor-ed course from 5 - 9 October 2026. Phase II consists on introducing practical methods code notebooks on Hydrological forecasting The phase aims to provide participants with a more interactive sessions allowing them to become familiar with tools and script that facilitate the understanding of hydrological forecasting methods and the HydroSOS methodology. 

## Objectives:
Phase II aims to provide participants with a guided, hands-on experience using interactive notebooks that apply the hydrological forecasting concepts introduced during Phase I. Participants will work directly with scripts implementing statistical, dynamical, and HydroSOS forecasting methodologies. The course will begin with a brief introduction to the Google Colab platform and the basic Python skills required to use the notebooks. The main focus of the course is to enable participants to run, understand, adapt, and interpret hydrological forecasting workflows and to generate HydroSOS hydrological status and outlook products through practical, hands-on exercises.

- Become familiar with the Google Colab platform for running and modifying hydrological forecasting notebooks.
- Learn the basic Python concepts required to work with the course scripts and workflows.
- Apply statistical hydrological forecasting methods using interactive notebooks and scripts.
- Apply dynamical hydrological forecasting methods using interactive notebooks and scripts.
- Understand and implement the HydroSOS methodology for generating hydrological status and outlook products.
- Generate and interpret HydroSOS products using real-world datasets and operational workflows.
- Gain practical experience in applying hydrological forecasting methods to support monitoring and decision-making.
